# Triage Labels

The skills speak in terms of five canonical triage roles. This repo's tracker spells every one of them exactly the same way:

`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`.

When a skill names a role (e.g. "apply the AFK-ready triage label"), use the matching label string verbatim. Renaming any of them here means renaming it in the tracker too.
